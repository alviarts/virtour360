## Teramati Langsung (dari teks halaman)
Tagline, struktur navigasi, isi demo UI (issue, thread, PR, kode), nama fitur, copy, changelog (Nov 2026), warna brand resmi (#08090a, #F7F8F8, #232326), radius contoh (0/7/14 px), prinsip Linear Method.

## Tidak Bisa Diverifikasi (perlu Anda cek)
| Hal | Cara cek |
|---|---|
| Font, ukuran, tracking | DevTools → Computed |
| Skala spacing, grid, lebar maksimum | DevTools → Layout |
| Warna abu perantara, warna aksen status | DevTools → Styles / color picker |
| Easing dan durasi animasi | DevTools → Animations |
| Perilaku di dalam aplikasi (shortcut, command menu, tema terang) | Login dan coba langsung |
| Kontras sebenarnya, dukungan reduced-motion | Lighthouse / axe |

## Catatan Hak Cipta
Linear melarang pengubahan atau penggunaan aset logo/brand seolah berafiliasi. Gunakan analisis ini sebagai **inspirasi pola**, bukan menyalin aset atau identitas visual.
