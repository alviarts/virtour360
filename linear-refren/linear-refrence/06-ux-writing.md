# 06. UX Writing dan Microcopy

## Karakter Suara
- **Ringkas, deklaratif, percaya diri.** Judul = pernyataan, bukan pertanyaan.
- **Konkret.** "Faster app launch", "Reduce ETA jitter": judul issue memakai kata kerja + objek.
- **Tanpa jargon buatan.** "Projects should be called projects."
- **Manusiawi di bagian demo.** Percakapan Slack tampak asli ("Anyone else noticing the iOS app feels slow…").

## Pola Copy yang Teramati
| Konteks | Pola | Contoh |
|---|---|---|
| Judul section | Kata benda + "and" + kata benda | "Intake and integrations", "Planning and monitoring" |
| Sub-judul | Satu kalimat, kata kerja imperatif | "Plan and navigate from idea to launch" |
| Tautan | Kata kerja + panah | "Learn more →", "View all →" |
| CTA | Singkat, 2 kata | "Get started", "Contact sales", "Open app" |
| Status project | Label + alasan | "At Risk: Project will likely delay with scope changes" |
| Waktu | Relatif | "2min ago", "just now", "4 min ago" |
| Atribusi sistem | Orang ketiga netral | "Linear created the issue via Slack on behalf of Karri" |
| Agen bekerja | Durasi | "Worked for 8 sec" |
| Changelog | Judul fitur + 1–2 kalimat + tanggal | "Mobile Diffs: Diffs … is now available for iOS and Android." |

## Pedoman Brand untuk Penamaan
- "Linear" bukan "Linear app".
- Rilis kapitalisasi proper noun: "Linear Reviews".

## Catatan
- Kalimat testimoni pendek dan spesifik ("Our speed is intense and Linear helps us be action biased").
- Hampir tidak ada "happy talk"; setiap kata menopang klaim.
