## Catatan Penting soal Keakuratan
Analisis ini berdasar halaman publik linear.app (home, /plan, /method, /brand, /quality).
Saya **tidak bisa membuka aplikasi Linear setelah login** dan **tidak bisa membaca CSS langsung**,
jadi nilai token (font, spacing, easing) yang tidak tercantum di halaman publik ditandai
**[verifikasi]**. Cek lewat DevTools sebelum dipakai sebagai angka final.
